# 🚀 Portfolio Engine

Build a premium, animated developer portfolio in under 60 seconds.

![Portfolio Engine](https://images.unsplash.com/photo-1460925895917-afdab827c52f?auto=format&fit=crop&q=80&w=2426)

## ✨ Features

- **4 Premium Themes**: Choose from Dark Dev, Minimal Clean, Creative Designer, or Glass Modern.
- **Dynamic Content**: Manage your projects, skills, and bio from a centralized dashboard.
- **NextAuth Security**: Safe and secure authentication with Google and Email providers.
- **Framer Motion**: Ultra-smooth animations and transitions for a professional feel.
- **Responsive Design**: Looks stunning on everything from mobile to 4K displays.

## 🛠️ Tech Stack

- **Framework**: Next.js 14+ (App Router)
- **Styling**: Tailwind CSS
- **Database**: PostgreSQL (Prisma ORM)
- **Auth**: NextAuth.js
- **Animations**: Framer Motion
- **Icons**: Lucide React

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/rammyajit07/Make-Your-Portfolio.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Database Setup**:
   - Create a project on [Supabase](https://supabase.com).
   - Copy your Connection URI to your `.env` file as `DATABASE_URL`.
   - Run: `npx prisma db push`

4. **Run the development server**:
   ```bash
   npm run dev
   ```
